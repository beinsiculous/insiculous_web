Heya folks!

Been awhile, so I figured I'd write up about the work I've been digging through on the engine. I regularly peruse the interwebs for the latest and greatest in AI workflows and to look at what people have been doing and building with AI. Since my last post there's been great model after great model released. I ended up throwing 20 bucks at the Deepseek Console API for their new flash model and found it to be just as good as Opus 5 or the Gemini model I was using - but it was super cheap! Even after all I've used it for I still have like 15 bucks left to spend, so overall a solid model that's so cheap you don't even need a sub. Kinda cool, and I love open-source platforms as well.

The real game changers tho were OpenAI's Astra and then the drop of Opus5.5. I had always struggled with image generation with AI to get a nice usable sprite-sheet. Google's nano-banana would do great work getting something that almost looked like a functional sprite-sheet, but it would never generate anything consistent or usable for that matter (in terms of animation). I had been experimenting with things like pixel lab and comfy-ui, but it was all getting intense, convoluted, and still nothing usable for my unique take on things. Then I saw online someone posting complete sprite animations, and the prompt they dropped into Astra to get it to draw (which was painfully simple). I wouldn't believe it if I didn't actually try it for myself, but having Astra draw pixel art using Aseprite was really that easy. From my previous attempts I already had a pretty fleshed out style and color guide, so some inconsistencies I see online I never really had to deal with. Seriously guys, all you gotta do is open Codex and tell it "Draw (your character idea), in Aseprite using (size, and colors)" - along with any other details and consistencies you want and it'll generate a LUA script that calls Aseprite via it's CLI interface and it will draw some properly sized and colored pixel art for you. Right now I tend to save 2 files for these generated sprites, one as a spritesheet as a .png file for actually using in games, and another .aseprite file that I use as the master for that character. It keeps it consistent on a level that frankly most AIs have failed at until now.

With this newfound pipeline to generate assets, I've finally taken the time to give the 6 arcade games I've already made more uniquely mine by bringing in characters from my yet-to-be released platformer Deion the Insiculous. I figure that way I can flesh out some concept art, add in some characters, and start building the insanely ridiculousness from the ground-up for every game I bring to the table. I'm still using Fable as my main orchestrator, but now that I have Astra in the mix I use it for any UI or art work that needs doing, and since Opus5.5 dropped I've been using it as my builder. Gemini and Kimi are still around reviewing plans and code before commits (which is good because the time it takes them to review makes sure my usage gets spread out a little bit more evenly lol). I also think the hand-off loop is doing a lot of good work in keeping my context windows clear and concise because I clear the worker's window before every batch they work on, and Fable's context window holds up well for maintaining the bigger vision.

The art revamps have been hitting each game accordingly, and I do believe they are all playable right now. I'm also giving the game page a fresh facelift, so be on the lookout for that shortly. My next big task that I'm taking on for the engine is something I'm really excited about - The Composer! I got this crazy big idea for how I want sounds and songs interaction with my game worlds, so I can't wait to build it out and talk about it more next time.

In the meantime I'm going to be deploying that facelift, taking care of some tech debt, and then finally building in music and sound effects to each of these arcade games. It distills the patterns and lessons from this book: https://gameprogrammingpatterns.com/ to help make sure the engine stays along the tried and true best practices path. Have fun out there and keep building and sharing with everyone!
